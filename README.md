# Excel-sales-and-customer-analysis-
This is a fully interactive  Excel dashboard that enables a regional sales manager to monitor performance against target,  identify top-performing products and regions, and understand which customer segments drive  the most revenue.
# Delivarables
# Deliverable 1 - One-Page BRD:
A written Business Requirements Document using the 
structure from Section 6.1 of this document. Submitted as a separate sheet named 'BRD' 
within the workbook.
# Deliverable 2 - Interactive Dashboard:
A single-sheet Excel dashboard meeting all 
minimum requirements listed in Exercise 2. The dashboard sheet must be named 'Dashboard'. 
# Deliverable 3 - Data and Pivot Sheets:
The workbook must include a 'Sales_Data' sheet 
with the raw data formatted as an Excel Table, and a 'Pivot_Tables' sheet containing the Pivot 
Tables that feed the dashboard.
